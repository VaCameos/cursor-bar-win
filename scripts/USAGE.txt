Cursor Bar for Windows
======================

这是托盘小工具，用来看 Cursor 套餐用量。不用单独登录。

怎么用
------

1. 先打开 Cursor 并登录
2. 双击 CursorBar.exe
3. 如果弹出「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」
   也可以右键 exe → 属性 → 勾选「解除锁定」→ 确定，再双击
4. 看任务栏右下角。如果没有图标，点 ^ 展开溢出区，把 Cursor Bar 拖到任务栏上
5. 左键图标打开用量面板，右键可以刷新、打开用量页或退出
6. 设置里可打开悬浮球：拖动能换位置，点击打开用量面板

可选：在本目录右键 install.ps1 → 使用 PowerShell 运行
会把程序装到「开始菜单」，并启动一次。

要求
----

- Windows 10 / 11
- 本机已安装并登录 Cursor
- 普通电脑用 win-x64 包；ARM 电脑（Surface Pro X 等）用 win-arm64 包
